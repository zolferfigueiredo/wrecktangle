# Security policy

## Supported versions

Only the latest release gets security fixes. Download the newest installer from [Releases](https://github.com/zolferfigueiredo/wrecktangle/releases) to update.

## Reporting a vulnerability

Please don't report it in a public issue. Use GitHub's [private vulnerability reporting](https://github.com/zolferfigueiredo/wrecktangle/security/advisories/new) instead.

Say what you found, how to reproduce it, and your Wrecktangle and Windows versions. You should get a reply within a week. Once a fix is released, the advisory is published with credit to you, unless you'd rather stay anonymous.
